# Угадай-ночь: Суздаль

Игра: 10 квартир, угадай цену за сутки. Данные — объявления Авито (Суздаль и окрестности).
Статический сайт: один файл `index.html` (данные внутри), без сборки.

## Баллы
За лот: `1000 × (1 − |ваша − реальная| / реальная / 0,5)`, минимум 0. Максимум за игру — 10 000.
Тип игрока: средняя относительная ошибка со знаком; ниже −7 % — «Жадный студент», выше +7 % — «Транжира», иначе — «Адекватный квартирант».
